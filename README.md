Taller: Formularios Reactivos
Proyecto desarrollado en Angular 19 utilizando Reactive Forms.

Descripción
La aplicación consiste en un formulario de registro de usuario que valida la información ingresada en tiempo real mediante Reactive Forms. no se usa ngModel. Incluye validaciones integradas de Angular, un validador personalizado para comprobar que las contraseñas coincidan y un resumen de los datos registrados.

Requisitos implementados
- Reactive Forms.
- Validaciones integradas.
- Validador personalizado de contraseñas.
- Mensajes de error por cada campo.
- Botón de registro deshabilitado cuando el formulario es inválido.
- Resumen del registro sin mostrar la contraseña.
- Limpieza del formulario después del registro.
- Estilos para campos válidos e inválidos.

Tecnologías utilizadas
- Angular 19
- TypeScript
- HTML
- CSS

Instalación

Instalar las dependencias.
npm install

Ejecutar el proyecto.
ng serve
Abrir el navegador en:
http://localhost:4200
